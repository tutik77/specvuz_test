## Особенности решения
1. **Общая концепция**: 
   Приложение, позволяющее собирать информацию о действиях клиентов и отдавать аналитику по ним. Основные плюсы решения - понятная масштабируемая архитектура, возможность адаптации под любые сценарии.

2. **Нормализация базы данных**: 
   - Типы событий вынесены в отдельную таблицу.
   - Установлена зависимость между таблицами через внешний ключ по ID события.

3. **Логика работы с типами событий**:
   - Используются идентификаторы (ID) для работы с типами событий вместо их названий.
   - Реализована возможность задавать собственные коды для определенных событий, что позволяет строить архитектуру типов и вдальнейшем упростит аналитические вычисления.

4. **Запуск проекта**:
     ```bash
     docker-compose up -d
     uv run uvicorn main:app --host 0.0.0.0 --port 8000
     ```
